Perfiles y estrategias

Todos los perfiles comparten el mismo presupuesto de potencia. La prioridad del perfil establece el orden de asignación. Cada perfil define participantes, estrategia y opciones. Las condiciones del sensor pueden impedir la activación de un perfil completo.

Las ocho estrategias aparecen a continuación. Según la estrategia se configuran saltos de dispositivos que no caben, ventanas de tiempo, rotación, mejora mínima e intervalo de optimización. Las potencias son valores de planificación.

Perfiles y estrategias

  • Round Robin: turnos entre consumidores aptos.
  • Tiempo justo: prioridad a menor tiempo confirmado.
  • Energía justa: prioridad a menos Wh estimados recibidos.
  • Prioridad fija: prevalece el orden configurado.
  • Máxima eficiencia: busca una combinación que aproveche más excedente.
  • Potencia ascendente: primero las cargas pequeñas.
  • Potencia descendente: primero las cargas grandes.
  • Funcionamiento estable: minimiza cambios innecesarios.

Horarios semanales por perfil (desde 0.9.5)

En Perfiles → Editar puedes activar un horario independiente para cada perfil. Cada franja admite varios días, inicio, fin y varias franjas por día.

Los horarios de perfil y consumidor son independientes. Para iniciar se necesitan el perfil activado, ambos horarios permitidos y las condiciones de sensores válidas. Después, la estrategia decide qué carga elegible inicia.

Al terminar la franja del perfil, RRH solicita el apagado confirmado de las cargas activas que controla; puede agrupar el apagado de varias. No asume el control de equipos encendidos externamente.

Las franjas que cruzan medianoche pertenecen al día inicial. Se respeta la zona horaria de Home Assistant y los cambios de hora. El panel muestra la próxima apertura.
