Configuración

Tras el aviso de seguridad puedes elegir Asistente, Modo demo o Omitir configuración. La demo utiliza seis consumidores simulados y nunca envía comandos a equipos reales. Omitir deja RRH apagado.

El asistente solicita el sensor de potencia de red y el signo de exportación, nombre y vatios de cada consumidor, estrategia, datos fotovoltaicos y precios, reserva de potencia, retraso por déficit y antigüedad máxima del sensor. Revisa el resumen antes de guardar. Los dispositivos de varias etapas o regulación continua se ajustan desde el editor completo.

Puedes volver a iniciar el asistente desde Ajustes. La opción de no volver a mostrar el aviso afecta solo al aviso de seguridad.

Seleccionar entidades en 0.9.5

La configuración ofrece selección de entidades Home Assistant con búsqueda. Escribe parte del nombre o del ID y elige un resultado; cada campo limita los tipos de entidad.

Funciona también en móviles. Si el selector nativo no está disponible, queda una alternativa compatible. Añade después las franjas semanales en Consumidores y Perfiles.

El control automático sigue necesitando activación expresa, medidas válidas y comprobaciones de seguridad.
