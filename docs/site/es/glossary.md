# Glosario

- **RRH**: Round Robin Hood, reparto de excedentes FV.
- **Vertido**: potencia exportada a la red (W).
- **Reserva**: margen de potencia que no se asigna.
- **Histéresis**: margen para impedir oscilaciones cerca del umbral.
- **Potencia nominal**: estimación por dispositivo, no lectura real.
- **Demo**: simulación aislada sin comandos reales.
- **kWh**: energía acumulada; **W/kW**: potencia instantánea.
- **Apagar todo**: comando de software, no un interruptor físico.
