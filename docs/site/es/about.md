# Acerca de

**Round Robin Hood** es una integración Home Assistant de **Satisfried** (Satisfried_yt), creada originalmente para uso personal con ayuda de inteligencia artificial. Ayuda a consumir el excedente fotovoltaico en casa.

La página Acerca de muestra la versión RRH y la versión Home Assistant Core cuando está disponible. No es un dispositivo de protección ni un contador calibrado.
