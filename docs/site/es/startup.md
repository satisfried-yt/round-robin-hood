# Comportamiento tras reinicio

Elige **Siempre APAGADO** (recomendado), **Siempre ENCENDIDO** o **Restaurar último estado**. La última opción diferencia entre ENCENDIDO, Pausa y APAGADO.

Antes de reactivar el reparto RRH espera una nueva lectura válida de red y estados confirmados de todos los dispositivos. Una configuración manual con sensor, consumidor y perfil válidos es suficiente, sin necesidad de finalizar el asistente. No envía comandos de encendido basándose solo en estados guardados. Siempre APAGADO no apaga físicamente equipos que sigan encendidos.
