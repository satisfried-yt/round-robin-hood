# Glossar

| Begriff | Erklärung |
|---|---|
| **PV** | Photovoltaik, elektrische Solarstromerzeugung. |
| **Einspeisung / Export** | Aktuell zum öffentlichen Netz abgegebene W; die Messwert-Vorzeichenrichtung ist konfigurierbar. |
| **Netzbezug / Import** | Aus dem Netz bezogene Leistung. |
| **W** | Watt: momentane Leistung. Eine Anlagengröße von 4 kW wird als 4000 W eingegeben. |
| **Wh / kWh** | Energie aus Leistung × Zeit; 1000 W eine Stunde = 1 kWh. |
| **kWp** | Nennleistung unter Standardtestbedingungen; RRH zeigt die Anlagenleistung in W an. |
| **Reserve** | Nicht zu vergebende Watt als Schutzabstand. |
| **Hysterese** | Abstand, ab dem ein Schalt-/Regelzustand wieder zurückwechseln darf. |
| **Zuteilung / Allocation** | Durch RRH geplante und bestätigte Nutzung eines Geräts. |
| **Fairness-Gutschrift** | Anrechenbare RRH-Laufzeit oder geschätzte zugeteilte Wh; getrennt von der allgemeinen Statistik. |
| **Strikt / Überspringen** | Entweder auf nächsten Kandidaten warten oder mit leistungsgerechtem Kandidaten weitergehen. |
| **Restüberschussverbraucher** | Nachrangiges regelbares Gerät für verfügbare Leistung nach normalen Profilen. |
