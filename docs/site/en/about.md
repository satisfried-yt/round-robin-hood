# About Round Robin Hood

**Round Robin Hood (RRH)** is a Home Assistant integration that allocates photovoltaic export surplus to configurable appliances. **Satisfried** (Satisfried_yt) originally created it for personal use, with the assistance of artificial intelligence.

It supports allocation strategies, profiles, switches and adjustable consumers, sensor conditions, safety margins, an isolated demo, estimated energy/cost statistics, a setup wizard and integrated documentation.

**Important:** RRH is not a certified safety controller, a physical disconnect or a calibrated energy meter. Read [Safety](safety.md) before using it. Financial figures are estimates rather than guaranteed savings.
