# Glossario

- **RRH**: Round Robin Hood, assegnazione surplus fotovoltaico.
- **Immissione**: potenza esportata in rete (W).
- **Riserva**: margine di potenza non assegnato.
- **Isteresi**: banda che evita commutazioni oscillanti vicino alla soglia.
- **Potenza nominale**: stima per dispositivo, non consumo misurato.
- **Demo**: simulazione isolata senza comandi reali.
- **kWh**: energia accumulata; **W/kW**: potenza istantanea.
- **Spegni tutto**: comando software, non sgancio fisico.
