# Sobre

**Round Robin Hood** é uma integração Home Assistant de **Satisfried** (Satisfried_yt), iniciada para uso pessoal e criada com apoio de inteligência artificial. Ajuda a aproveitar o excedente fotovoltaico em casa.

A página Sobre apresenta a versão do RRH e, quando disponível, do Home Assistant Core. O software não substitui equipamento de proteção certificado nem contador calibrado.
