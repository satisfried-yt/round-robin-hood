# Comportamento no reinício

Escolha **Sempre DESLIGADO** (recomendado), **Sempre LIGADO** ou **Restaurar último estado**. O último estado distingue LIGADO, Pausa e DESLIGADO.

Antes de retomar a distribuição, o RRH espera uma **nova leitura de rede válida** e os estados confirmados dos dispositivos. Uma configuração manual com sensor, consumidor e perfil válidos é suficiente. Não envia comandos baseados apenas em estados guardados. Sempre DESLIGADO não é um comando de corte elétrico.
