# Sensores do Home Assistant

O **sensor de rede** fornece potência instantânea W/kW, não energia cumulativa em kWh. Verifique o sinal de exportação no Home Assistant.

**Preços** requerem valores numéricos e unidade compatível por kWh (`EUR/kWh`, `ct/kWh`). Potência PV: W/kW; energia PV: Wh/kWh/MWh. `unknown`, `unavailable` e valores não numéricos são inválidos. No arranque automático, um valor restaurado sem nova medição não autoriza comutações.
