# Glossário

- **RRH**: Round Robin Hood, distribuição de excedente solar.
- **Injeção**: potência exportada para a rede (W).
- **Reserva**: margem não distribuída.
- **Histerese**: banda para evitar oscilações próximas do limite.
- **Potência nominal**: estimativa, não consumo medido por aparelho.
- **Demo**: simulação isolada sem comandos reais.
- **kWh**: energia acumulada; **W/kW**: potência instantânea.
- **Desligar tudo**: comando de software, não corte físico.
