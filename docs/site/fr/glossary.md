# Glossaire

- **RRH** : Round Robin Hood, répartition de surplus solaire.
- **Injection** : puissance envoyée vers le réseau (W).
- **Réserve** : marge de puissance qui n’est pas allouée.
- **Hystérésis** : intervalle qui évite l’oscillation autour d’un seuil.
- **Puissance nominale** : valeur estimée d’un appareil, pas une mesure individuelle.
- **Mode démo** : simulation isolée, sans commandes HA réelles.
- **kWh** : énergie cumulée ; **W/kW** : puissance instantanée.
- **Tout arrêter** : demande logicielle d’arrêt, pas un coupe-circuit physique.
