# Configuration

Après la notice de sécurité, choisissez **Assistant**, **Mode démo** ou **Ignorer**. Le mode démo utilise six charges virtuelles distinctes ; il ne commande jamais les appareils réels. Ignorer laisse RRH à l’arrêt.

L’assistant demande le capteur de puissance réseau, le signe d’exportation, le nom et la puissance de chaque appareil, une stratégie, les tarifs, la réserve, le délai de déficit et l’âge maximal des mesures. Vérifiez le résumé avant d’enregistrer. Les appareils à plusieurs niveaux se configurent ensuite dans l’éditeur complet.

Vous pouvez relancer l’assistant depuis **Paramètres**. Le choix de ne plus afficher l’avertissement concerne seulement cet avertissement.
