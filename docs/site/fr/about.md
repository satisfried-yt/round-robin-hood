# À propos

**Round Robin Hood** est une intégration Home Assistant réalisée par **Satisfried** (Satisfried_yt), initialement pour son propre usage et avec une assistance par intelligence artificielle. Elle aide à utiliser l’électricité photovoltaïque plutôt qu’à l’injecter dans le réseau.

L’onglet « À propos » affiche la version RRH et la version de Home Assistant Core si disponible. L’outil n’est ni un système certifié de sécurité ni un compteur étalonné.
